# Online Appointment & Patient Record Management System

## Problem Statement

Many clinics and hospitals still use manual registers to manage patient details, doctor appointments, and treatment history. Managing records manually can lead to data loss, errors, difficulty in accessing information, and inefficiency.

## Solution

The Online Appointment & Patient Record Management System is designed to digitally manage patient records and doctor appointments. The system helps organize patient information, schedule appointments, and maintain treatment history efficiently.

## Key Features

- Patient registration and record management
- Doctor appointment booking
- View and manage patient details
- Maintain treatment history
- Manage appointment details
- Easy access to patient records
- Efficient and organized data management

## Tech Stack

- Java
- MySQL
- HTML
- CSS
- GitHub

## Project Objective

The main objective of this project is to provide a simple and efficient digital system for managing patient records and doctor appointments while reducing the problems associated with manual record keeping.

## Expected Outcome

A functional application that allows users to manage patient records and doctor appointments efficiently with proper CRUD (Create, Read, Update, Delete) functionality.
